# 同底盘context交换预测测试

本次结论：09、11相对无swap的03，在同底盘跨回合交换时的整体预测变化较小，但03→09同时改变注入方式，不能单独归因于新增损失。09绝对预测误差更高；11的交换后绝对误差最低。10即使相对交换增幅小，绝对误差和预测变化仍大，不能视为成功。

数据核验：全部100条轨迹保存的实际车型ID、质量和最大前轮角与配对元数据逐帧一致；所有输出数组有限。一步有效受体2059个，每个20个同底盘供体。供体来自其他地图、其他真实回合，采集策略相同；原始速度/轮角自然变化，不作人工固定。

进一步限制：09整体预测变化L1下降，但前轮角单项的变化0.00526rad仍高于03的0.00354rad，因此并非所有物理维度都更不敏感。需要严格的Deep+swap0/1同预算对照才能归因；本次不启动新训练。

## 解释边界

- 相同底盘下误差增幅小，并且异底盘/零context明显变差，才支持context具有可互换的车辆响应信息；所有交换都无影响可能意味着忽略context。
- 不能由03→09的差异单独证明一致性损失有效，因为Deep条件注入也改变了。08纯交换实验只有约47K，不能与500K作完整预算对照。
- 区间以10张地图为聚类单位配对bootstrap10000次，包含固定抽样供体的平均效果，不覆盖训练种子或重新采样供体的不确定性。没有预先指定等效界值，因此不宣称严格统计等效。
